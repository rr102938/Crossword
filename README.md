# Crossword Puzzle Solver (CS50 AI)

## What it does
* This is a Python program that solves crossword puzzles by framing them as constraint satisfaction problems (CSPs).
* It uses backtracking search, node consistency, arc consistency (AC-3), and heuristic functions to automatically assign words to crossword structures.

## Technologies Used
* Python
* Constraint Satisfaction Problem (CSP) algorithms
* Git / GitHub

## How to Run It
* Make sure you have the required game files (structure and vocabulary files) in your directory.
* Run the generator script with your structure and words files:
* "```bash"
* python generate.py structure.txt words.txt
* View the generated solution output in your terminal or output image.
